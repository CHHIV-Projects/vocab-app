## What the architecture experiment demonstrates

Source ID/POS/order are entirely code-owned and each request has one source; the
within-request multi-item shift mechanism cannot occur in the same form. It does
**not** eliminate wrong definitions or unsupported embellishment. Structural
reliability still failed for 4/21 and only 5/7 senses passed all three requests.
Identical strings show text stability, not semantic repeatability. Human semantic
judgments and learner-value comparison are still needed before recommending a
production role.

No learner redesign, model/prompt/validator production change, semantic relinking,
data/cache write, alternate run or weight download occurred. Existing protected
app/DB container identities/start times and production source hashes are unchanged.
The pilot directory and application runtime were mounted read-only during this run.

The inference script's manifest preserves the exact code hash used during execution.
After execution, only the exporter was extended to include explicit model/manifest/
artifact identities in the repository report; no inference contract was changed or
rerun. Pre-run 29 offline harness/synthesis tests passed; four narrow tests passed
again after the reporting-only extension.
