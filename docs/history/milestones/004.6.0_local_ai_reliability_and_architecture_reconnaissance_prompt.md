# 1. Objective

Perform an exhaustive architectural reconnaissance of the Vocab App's current local-AI system and determine the safest, most reliable direction for the next local-AI architecture.

This milestone is NOT:

- a fix for `Utilitarian`;
- a prompt-tuning exercise;
- an implementation milestone;
- a model-download milestone;
- a runtime migration;
- an embedding implementation;
- a benchmark execution milestone;
- a frontend milestone.

The primary question is:

> What is the smallest, fastest, most deterministic local-AI component or combination of components that can reliably perform each semantic task required by the Vocab App on the actual `henderson-server1` hardware?

The broader engineering objective is:

> Determine how local AI can become a dependable software component rather than a probabilistic application controller.

The reconnaissance must challenge the current architecture rather than assume GPT-OSS:20b, Ollama, or the current staged synthesis pipeline is the optimal final design.
