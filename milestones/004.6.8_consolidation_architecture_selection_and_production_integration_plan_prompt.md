# 1. Objective

M004.6.8 follows the completed M004.6.0–M004.6.7 Local-AI Reliability and Consolidation Architecture reconnaissance arc.

That arc has now produced enough evidence to select a production consolidation direction.

The controlling findings are:

- source senses remain canonical and complete;
- learner-meaning consolidation is a semantic task;
- Python must own identity, completeness, topology, persistence, and validation;
- Qwen3:8b is the strongest measured bounded semantic model for this task;
- single-pair Qwen judgments are substantially more reliable than batched or candidate-proposal approaches;
- the original global embedding threshold failed expanded high-recall validation;
- Top-K embedding screening reached 100% recall only with weak workload reduction;
- deterministic structural screening missed approved merges;
- bounded Qwen candidate proposal achieved only 50% approved-merge recall and added substantial latency/complexity;
- approximately 90.4% of lexical partitions contain one sense and require no pairwise semantic work;
- approximately 98.2% contain three or fewer senses;
- only approximately 0.045% of partitions exceed 20 senses;
- the large-partition performance problem is therefore highly concentrated;
- exhaustive Qwen production economics are materially better than earlier benchmark projections once model/seed benchmark multipliers are removed;
- successful semantic results can be versioned and cached rather than recomputed on every lookup.

The selected architectural direction entering this milestone is therefore:

canonical source senses
    ->
deterministic POS/material partition
    ->
if one eligible source sense:
    deterministic learner-container pass-through
else:
    exhaustive bounded Qwen single-pair semantic judgments
    ->
Python-owned conservative complete-link clustering
    ->
deterministically assembled learner-meaning containers
    ->
versioned validation
    ->
persistent cache

Operationally:

ordinary small/medium partitions:
    lazy/on-demand consolidation is acceptable

large/pathological partitions:
    asynchronous preparation and/or background warming

cached valid result:
    zero repeated semantic-model work unless evidence/model/contract identity changes

M004.6.8 must convert that evidence into a precise production architecture and a safe implementation roadmap.
