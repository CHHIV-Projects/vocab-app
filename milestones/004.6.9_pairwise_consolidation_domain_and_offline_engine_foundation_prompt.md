# 1. Objective

    ->

# 17. Coverage Invariant

Implement a deterministic validator for complete semantic coverage.

For a partition with expected pair set P, topology finalization is allowed only when:

- actual logical pair IDs exactly equal P;
- every expected pair appears exactly once logically;
- every pair belongs to the same compatible partition/evidence/contract/model/options identity;
- every pair has status equivalent to `succeeded_validated`;
- no foreign pair exists;
- no pair is missing;
- no duplicate logical pair exists.

Any failed/retryable/terminal/incomplete pair must block normal topology finalization.

Do not treat a terminal failure as completed semantic coverage.

Provide explicit validation diagnostics/errors.

# 18. UNCERTAIN Semantics

`uncertain` is a valid completed semantic judgment.

It satisfies pair coverage.

It does NOT provide positive merge evidence.

For topology purposes:

- `merge` = positive edge;
- `keep_separate` = blocked edge;
- `uncertain` = blocked edge.

This policy should be explicit in code/tests.

# 19. Deterministic Complete-Link Clustering

Implement the M004.6.8 selected algorithm exactly.

Start with singleton containers in stable source-sense-ID order.

Then:

1. scan container pairs in deterministic stable order;
2. merge two containers only when EVERY cross-container source-sense pair has a validated `merge` judgment;
3. if any cross edge is `keep_separate` or `uncertain`, do not merge;
4. after a successful container merge, restart deterministic scanning;
5. stop when no further legal merge exists.

Do not use naive union-find.

The output must be deterministic for the same validated judgment set.
