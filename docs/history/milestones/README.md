# Vocab Historical Milestones

This directory contains the 58 legacy pre-Repo-Control milestone artifacts formerly stored at repository-root `milestones/`. These files are historical evidence, not active Repo Control lifecycle candidates. Their filenames and bytes are preserved; legacy naming inconsistencies are intentionally not normalized. Internal references that name the former root or path are retained as historical references rather than rewriting old evidence.

The exact source-to-destination mapping is listed in [legacy_milestone_path_manifest.md](legacy_milestone_path_manifest.md). M001.000 and M001.001 are closed Repo Control lifecycle sets stored under [`../../milestones/`](../../milestones/). Their embedded references to the former `milestones/` root are retained verbatim as historical evidence; the moved files can be found by their unchanged filenames under `docs/milestones/`. During Phase A, temporary M001.002 recovery copies were also kept under the old root. After the Product Owner's registry cutover and successful canonical-root Coder status verification, those recovery copies were removed; repository-root `milestones/` is now retired. The active M001.002 lifecycle lives under [`../../milestones/`](../../milestones/).

The standalone historical `M004.4_..._prompt.md` has no same-named closeout in the legacy corpus. It is retained exactly as found and is not assigned active lifecycle status.
