# 15. Prompt Policy

The system/user prompt must clearly define:

## MERGE

Use when the two senses represent the same learner-facing meaning, including accepted cases such as:

- near paraphrase/duplicate;
- minor contextual variant;
- appropriately consolidatable specialization under the established product policy.

## KEEP SEPARATE

Use when they represent meaningfully distinct learner uses, including:

- related but distinct;
- materially different;
- significant specialization/boundary that should remain visible separately.

## UNCERTAIN

Use only when the provided evidence is insufficient to decide safely.

Safety policy:

> false split is preferred to unsafe false merge.

Do not ask the model to create containers, rank meanings, or reason about final topology.
