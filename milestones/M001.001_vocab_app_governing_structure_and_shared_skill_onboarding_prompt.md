## 1. Objective

6. Reuse the accepted Repo Control three-Skill baseline rather than creating a Vocab-specific procedural fork.
7. Coding agents still must not perform Git stage/commit/push/tag/merge/rebase/reset/stash/clean/branch/remote mutations.

This milestone is documentation/process onboarding only. It does not authorize application feature work.
