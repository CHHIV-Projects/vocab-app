## 6. Safety Disposition

**Configuration B is rejected.** Simply restoring historical prompt wording
while retaining the hardened v2 schema introduces an unsafe false merge on
known separate-worthy evidence.

No unsafe experimental result was persisted as an accepted production
judgment, topology, or contract. The experimental wording was restored rather
than retained. The current accepted M004.6.13 v2 worktree behavior remains in
place.

## 7. What This Experiment Proves

- Restoring the historical prompt wording while retaining the hardened schema
  is not a safe production correction.
- A decision/reason pair can be contract-valid yet semantically wrong.
- Schema compatibility enforcement alone does not guarantee semantic
  correctness.
