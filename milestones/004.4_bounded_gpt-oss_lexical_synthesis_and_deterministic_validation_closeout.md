## 5. Deterministic complete scaffold

Each package receives source-order aliases:

```text
S001 -> canonical source sense ID
S002 -> canonical source sense ID
...
```

A closed required-key schema requires every alias under `sense_results`. GPT returns only one learner-friendly paraphrase per required alias. Code owns POS, canonical IDs, labels, examples, forms, pronunciation, etymology evidence, provenance, and source coverage.

Missing aliases, unknown aliases, empty definitions, cross-POS reassignment, and malformed structures hard-fail. Canonical IDs never change to aliases in evidence hashes, diagnostics, cache identity, or future accepted provenance.

## 6. POS-local semantic grouping

After first-stage validation, code partitions each POS by material source-label signature so the model cannot merge distinctions such as archaic, obsolete, rare, regional, vulgar, offensive, slang, dated, or technical into an unrestricted group.

For each POS-local partition:

- every alias is required exactly once;
- group IDs are bounded to `G001...Gnnn`;
- every allowed group-definition slot is present;
- unused slots are explicit empty strings;
- every used group has a nonempty learner definition;
- unknown aliases/groups and missing assignments fail;
- grouping never crosses POS or material-label partitions.

The exact implemented material-label partition allowlist is:

```text
archaic, dated, figurative, formal, humorous, informal, literary,
obsolete, offensive, rare, regional, slang, technical, vulgar
```

These labels are partitioned because merging them away can materially change appropriate use or interpretation. A figurative and unmarked sense, for example, cannot be merged into one learner group. All other source labels remain canonically preserved even when they are not hard partition boundaries. This is an intentional fixed allowlist for M004.4, not a broad taxonomy or a claim that every unlisted source label is semantically interchangeable.

Code then merges partition results back into one complete POS group set. A separate per-POS core-selection call selects at most five group IDs. Code computes:

```text
Additional Groups = All Validated Groups - Core Groups
```

Thus no unselected group can disappear. The 3-5 target is approximate and per POS, with fewer where appropriate.

- U.S. pronunciation uses explicit `US` or `General-American` tags only.
- Forms, examples, labels, pronunciation, etymology evidence identity, and provenance remain code-controlled.
- WordNet remains separate supplemental evidence.

### Synonyms

Canonical Wiktionary relation evidence and separate WordNet evidence are preserved in the synthesis projection with provenance. However, the current final grouped learner meanings do **not** attach organized synonym lists. Grouped meanings currently emit empty `synonyms` arrays; richer learner-group synonym association is deferred to M004.5. No unsupported synonym can enter a validated result because the final validator rejects any synonym whose evidence ID and term are not present in the supplied source relation evidence.

### Etymology

M004.4 does not generate a learner-friendly etymology summary. It preserves deterministic Wiktionary etymology text/templates and an evidence ID in the validated result's code-controlled deterministic facts. Learner-facing etymology presentation or summarization remains M004.5 work.
