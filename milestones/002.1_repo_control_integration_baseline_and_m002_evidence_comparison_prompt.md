# 1. Objective

Integrate the canonical Vocab App repository into the existing Repo Control workflow and evaluate Repo Control against the independent architecture reconnaissance already completed in M002.

M002 was intentionally completed through conventional coder reconnaissance before this comparison.

That gives M002.1 a useful control case:

`independent coder reconnaissance`

versus

`Repo Control deterministic/context/review evidence`

The purpose is not to determine whether Repo Control can replace the coder or Architect.

The purpose is to determine:

1. whether Repo Control correctly understands the canonical Vocab repository;
2. whether its deterministic Context surfaces the important files, symbols, relationships, and tests relevant to real Vocab work;
3. where Repo Control evidence agrees with M002;
4. where it adds useful evidence not emphasized by M002;
5. where it omits important information;
6. where it produces duplicate, noisy, misleading, stale, or difficult-to-interpret evidence;
7. how Product Owner Review behaves against a real application repository;
8. whether local-AI assessment adds useful interpretation or primarily human-facing commentary;
9. how Snapshot and Comparison behave on the canonical Vocab repository;
10. whether guarded Stage and Commit are ready to become the normal Vocab Git workflow;
11. what Repo Control capabilities should become standard for subsequent Vocab milestones;
12. what genuine Repo Control gaps, if any, should be handled through separate Repo Control milestones.

M002.1 must leave the Vocab application itself unchanged.

Do not modify Repo Control to improve the results observed during this milestone.

Preserve the evidence as observed.
