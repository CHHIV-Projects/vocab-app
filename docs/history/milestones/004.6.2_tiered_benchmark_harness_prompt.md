# 1. Objective

M004.6.2 builds directly on M004.6.1.

M004.6.1 established that:

- both `gpt-oss:20b` and `qwen3:8b` can satisfy the measured core-selection structured contracts;
- `qwen3:8b` requires benchmark-local `think: false` for this bounded task because reasoning consumed the output budget before final JSON;
- Qwen was materially faster for the measured bounded task;
- the current subset-array contract remained structurally reliable in the measured sample;
- the fixed-key ranking contract was also structurally reliable and is safer by construction for identity/topology;
- neither contract has yet been shown to be semantically superior;
- the historical `Utilitarian` failure root cause remains unknown;
- no production synthesis change is yet justified.

The objective of M004.6.2 is:

> Generalize the M004.6.1 experiment into a small, reproducible tiered benchmark harness and perform the first human-review-ready semantic comparison of the two core-selection contracts and the two installed models.

This milestone should answer:

1. Can the benchmark reproducibly execute a defined Tier 1 lexical set?
2. Can structural validity, semantic review, performance, and artifact identity be kept separate and auditable?
3. Do `gpt-oss:20b` and `qwen3:8b` differ materially in core-selection quality on a broader but still bounded lexical sample?
4. Does the fixed-key ranking contract preserve or improve semantic quality compared with the subset-array contract?
5. Are there lexical categories where one model or one contract becomes materially less reliable?
6. Is the benchmark infrastructure sufficient to support M004.6.3 without further redesign?

This milestone is NOT:

- a production synthesis change;
- a full 100+ word reliability benchmark;
- a grouping redesign;
- an embedding implementation;
- a runtime bake-off;
- a model-download milestone;
- a final model-selection milestone;
- a production architecture-selection milestone.

# 19. Human Semantic Review Rubric

Use a compact anchored rubric.

For each fixture/configuration evaluate:

## Core Meaning Coverage

- 2 = all clearly important learner meanings retained;
- 1 = mostly correct, but one meaningful omission/question;
- 0 = materially important meaning omitted.

## Core Precision

- 2 = selected core set contains only meanings reasonably central for a learner;
- 1 = includes a questionable secondary meaning;
- 0 = materially over-selects obscure/secondary meanings.

## Meaning Preservation

- 2 = no obvious semantic distortion from candidate definitions;
- 1 = ambiguous/questionable;
- 0 = materially misleading selection.

## Overall

Use:

- PASS;
- QUESTIONABLE;
- FAIL.

The review must permit written notes.

Do not create a complicated scoring system in this milestone.
