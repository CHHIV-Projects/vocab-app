# 1. Objective

M004.6.13 successfully solved one structural reliability problem:

Qwen could previously emit internally incompatible decision/reason combinations such as:

`merge / specialized_subsense`

which then failed deterministic validation and could repeat identically until the pair became terminally blocked.

The M004.6.13 v2 contract corrected that problem by introducing:

- a complete seven-combination decision/reason allowlist;
- a constrained `oneOf` structured-output schema;
- contract-version-aware validation;
- v1/v2 identity separation;
- preservation of historical v1 data.

However, targeted semantic validation then exposed a second issue.

Under current v2:

- known MERGE fixtures such as `charge` and `cleave` returned `keep_separate`.

Under the M004.6.13.1 Configuration B experiment:

historical prompt
+
hardened `oneOf` schema

a known MERGE fixture returned a valid `merge`, but a known KEEP-SEPARATE fixture also returned an unsafe:

`merge / contextual_variant`.

Therefore neither isolated examples nor additional ad-hoc prompt tuning are sufficient to choose the production semantic contract safely.

M004.6.13.2 must perform a small, frozen, reproducible calibration benchmark across the four already-defined prompt/schema configurations using the SAME human-adjudicated reference pairs.

The milestone must measure the tradeoff between:

- unsafe false merges;
- legitimate merge recall;
- keep-separate accuracy;
- contract-invalid outputs.

This milestone is BENCHMARK-ONLY.

Do not alter production semantic behavior.

# 2. Central Question

Determine:

> Which component of the current contract — prompt wording, schema shape, or their interaction — materially changes Qwen's merge/separate behavior, and does any already-defined configuration provide both acceptable merge recall and zero observed unsafe false merges on a frozen human-adjudicated calibration sample?

The benchmark must answer this with measurements rather than individual anecdotes.

"the prompt caused it"

or:

"the schema caused it"

from one pair.

Base the conclusion on changes across the complete frozen sample.

Example:

If A and C have similar merge recall but B/D both collapse merge recall, that is evidence the schema shape is influencing semantic selection.

If A/B behave similarly but C/D collapse merge recall, that is evidence the prompt wording is influencing semantic selection.

If all configurations perform similarly, the issue is more likely model/reference behavior rather than the M004.6.13 changes alone.
