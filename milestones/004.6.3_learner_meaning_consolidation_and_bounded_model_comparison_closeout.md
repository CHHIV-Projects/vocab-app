## 6. Equivalence contract and invocation

The only model-owned result is a closed, bounded relationship:

```json
{
  "relationship": "same"
}
```

Allowed enum values are `same`, `distinct`, and `uncertain`. `same` means substantially the same learner concept with primarily contextual/application differences. `distinct` means the learner needs a genuinely different meaning. `uncertain` preserves ambiguity rather than forcing a merge.

Both models used three fresh fixed seeds: `4100`, `4101`, and `4102`.

## 8. Code-owned clustering

The runner uses `conservative-majority-union-find-v1`:

1. each source sense begins as its own code-owned node;
2. only a per-model majority `same` edge becomes merge evidence;
3. before union, code checks whether joining components would cross explicit `distinct` evidence;
4. a conflicting edge is blocked and recorded;
5. `uncertain`, non-majority, and blocked relationships remain safe splits;
6. code assigns stable `G001...` container IDs ordered by constituent canonical source-sense IDs.

No model invents a container ID or returns grouping topology. Each model creates its own code-owned container result from its own pair judgments; GPT-OSS and Qwen evidence is never combined to create a shared topology.

| Model | Source senses | Containers | Mean container/source ratio | Median ratio | Blocked conflict edges |
|---|---:|---:|---:|---:|---:|
| GPT-OSS | 38 | 31 | 0.799 | 0.847 | 4 |
| Qwen, no-thinking | 38 | 38 | 1.000 | 1.000 | 0 |

All eight generated container sets satisfied every required deterministic invariant:

- complete source-sense coverage;
- exactly-once membership;
- stable code-generated IDs;
- POS/material-local construction.

The four blocked GPT-OSS transitive conflict edges occurred in `running` adjective (1) and `cleave` verb (3). The conservative policy prevented unsafe transitive merges; no source sense disappeared or appeared in multiple accepted containers.
