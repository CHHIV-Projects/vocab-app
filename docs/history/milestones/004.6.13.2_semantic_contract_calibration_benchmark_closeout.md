   - Adding `SCHEMA_V2` to Prompt v1 eliminates all 13 contract-invalid outputs. However, Qwen adapts by mapping the 13 invalid outputs into valid merge reasons (`contextual_variant` or `paraphrase_or_duplicate`), causing 6 false merges on KEEP-SEPARATE pairs.

   - Adding Prompt v2 text ("The decision and reason must be internally consistent...") eliminates all 13 contract-invalid outputs by forcing Qwen to classify all 13 as `keep_separate / specialized_subsense`. This causes total merge suppression (0% merge recall).
3. **Prompt Effect under Hardened Schema (B vs D):**
   - Switching from Prompt v1 to Prompt v2 under `SCHEMA_V2` drops merge recall from 87.5% to 0.0% and eliminates all 6 false merges. Prompt v2 severely chills Qwen's willingness to output `merge`.
4. **Schema Effect under Prompt v2 (C vs D):**
   - Under Prompt v2, schema shape has zero effect: C and D yield identical 100% keep-separate and 0% merge recall results.
