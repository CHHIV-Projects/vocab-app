# Milestone M002.004 — Core Learner Experience Acceptance Polish

## 1. Scope Completed

Completed bounded learner-facing polish for deterministic lexical lookup:

- Kept short synonym lists visible with their meaning and collapsed longer lists per meaning.
- Corrected punctuation when multiple source gloss components are joined, without rewriting the source text.
- Added focused UI and workflow regression coverage.
- Completed real-word corpus, browser, and isolated PostgreSQL acceptance without touching production learner data or the installed lexical dataset.

## 2. Resulting Behavior

- A meaning with up to five synonyms shows them inline; longer lists have a per-meaning expander. Empty synonym lists do not add empty UI.
- Source gloss components ending in sentence punctuation are separated by a space; other components retain the semicolon separator. The `make` verb meaning now reads “To create. To build, construct, produce, or originate.” rather than displaying `.;`.
- The approved five-total initial-meaning policy and deterministic POS-first presentation remain intact. Additional meanings expand without losing POS grouping or source-sense identity.
- U.S. IPA is shown only when available. When absent, the pronunciation audio control remains available.
- Dataset status remains secondary to lookup and reports the installed dataset identity and date.
