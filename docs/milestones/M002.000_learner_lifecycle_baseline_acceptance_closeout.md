## 4. Architecture / Integration Notes

Learner path remains Streamlit -> framework-independent workflow -> canonical
read-only Wiktionary/Wiktextract evidence with separate WordNet supplement ->
bounded GPT-OSS:20b synthesis -> deterministic validation -> explicit PostgreSQL
acceptance. Automatic Qwen consolidation is not wired into this path.

PostgreSQL owns accepted entry/version/pointer state. Session state owns an unsaved
candidate; it may coexist with an accepted base. Pending Retry/Refresh preservation
requires matching normalized query/lemma, entry, version/active pointer, candidate
identity and evidence identity of the accepted base, plus candidate evidence integrity.
Retry retains the exact saved snapshot; Refresh intentionally may carry changed
evidence. The controller uses one helper boundary and computes saved-state Refresh
availability; the UI only handles presentation/session wiring.
